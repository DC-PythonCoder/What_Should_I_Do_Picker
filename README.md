# What Should I Do? 🎲

Have you ever been bored out of your mind yet unable to decide what to do? Well I have many times and I feel like this app will help me with that, that's why I created it. Maybe it will help you too. It is just a Python terminal program that randomly picks an activity for you to do based on the options you give it.

It does not have categories because what's the point in making a hard "Which category?" choice if you don't have to!

## Requirements

Python 3. No external packages are required.

## How to Run

(in the terminal)
```bash
python main.py
```

Enter `y` for another pick or `n` to exit and end the program with your final choice.

## Customise

Edit the lists in the `OPTIONS` dictionary in `main.py` to add your own choices.
